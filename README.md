
# NoteMate-Backend

## Getting started
```git clone https://github.com/andhariamonil/NoteMate-Backend.git```

```cd NoteMate-Backend```

```git checkout development```

Create .env file and add the credentials required in it.

Ref: sample.env

```npm install```

```nodemon .\src\server.js```

NoteMate-Backed should be now up and running!

NoteMate-Frontend git repo : ```https://github.com/andhariamonil/NoteMate-Frontend/tree/development```
